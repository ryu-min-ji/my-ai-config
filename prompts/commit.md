# /commit

이 기능은 깃 상태를 분석하여 Conventional Commits 형식으로 메시지를 작성하고 실제 작업 절차를 안내하는 슬래시 커맨드입니다. 절차는 다음과 같습니다:

1. **현재 상태 분석**:
   - `git branch`, `git status`, `git diff` 등을 실행하여 현재 브랜치와 변경 사항을 확인합니다.

2. **동기화 확인**:
   - `git fetch`와 `git rev-list`를 사용하여 로컬이 원격(origin)보다 앞서 있는지, 뒤처져 있는지 숫자로 보여줍니다.

3. **리베이스 제안**:
   - 원격에 새로운 커밋이 있다면 `git rebase`를 먼저 수행하라고 안내합니다.

4. **메시지 작성**:
   - 모든 준비가 완료되면 Conventional Commits 규격에 맞춰 커밋 메시지를 제안합니다.

이 커맨드를 통해 사용자는 커밋 준비 상태를 철저히 파악하고, 일관된 커밋 메시지를 생성할 수 있습니다.
